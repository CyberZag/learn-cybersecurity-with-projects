# Sources and attribution

The project began with a CleverTailor Pro suggestion for an inventory and support-ticket exercise on November 6, 2026. The assistant created this original offline Python adaptation and fictional data. The generated tutorial was not copied, and its suggestions to claim completed achievements were not followed.

Background sources reviewed November 6, 2026:

- [NISTIR 8011 Volume 2: Hardware Asset Management](https://nvlpubs.nist.gov/nistpubs/ir/2017/NIST.IR.8011-2.pdf), June 2017. Background on inventory assessment and unmanaged devices. This project does not implement or certify NIST compliance.
- [Microsoft Entra Lifecycle Workflow built-in tasks](https://learn.microsoft.com/en-us/entra/id-governance/lifecycle-workflow-tasks). Background on distinct leaver tasks, including disabling accounts and removing access. This simulation does not perform those tasks or call Microsoft services.

Two-person approval, state checks and evidence requirements are educational design choices, not universal operating procedures. There is no affiliation with any real employer or software vendor. Published verification was performed by the assistant; personal learner work must be recorded separately.
